# Programação Orientada a Objetos — Java

Repositório de atividades acadêmicas desenvolvidas para praticar conceitos de Programação Orientada a Objetos em Java.

## Conteúdos praticados

- classes e objetos;
- métodos e sobrecarga;
- herança;
- especialização de classes;
- organização de responsabilidades entre objetos.

## Projetos

### Sistema Bancário

Exercício voltado à modelagem de entidades e comportamentos de um sistema bancário.

### Sistema de Notificações

Exercício que trabalha diferentes formas de envio de notificações e especializações como e-mail, SMS e push.

## Contexto

Atividades realizadas durante a graduação em Análise e Desenvolvimento de Sistemas para consolidar fundamentos de Java e orientação a objetos.
